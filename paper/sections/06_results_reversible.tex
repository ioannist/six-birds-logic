\section{Reversible Embedding versus Erased XOR}
\label{sec:results-reversible}

Table~\ref{tab:reversible-erased} isolates the accounting point of the paper. All three rows describe the same CNOT laboratory with the same parameters: degeneracy \(d=3\), output noise \(p_{\mathrm{gate}}=0.02\), no memory noise, and a single tick, \(\tau=1\). The substrate does not change between rows; only the description presented to the layer does. In every row the input is the two-bit register \((a,b)\), so \(H_{\mathrm{in}}=2\) bits. The \emph{micro readout} reads the output as the full microstate, one of \(12\). The \emph{retained register} reads it as the four-valued register \((a,b)\). The \emph{erased output} reads only the target bit, which carries \(a\oplus b\), and forgets the control. In Six Birds terms the split happens at packaging (P5): keeping or discarding side information changes the carrier of the layer, and accounting (P6) records the consequences.

\paragraph{The retained register is closed and loses little.}
Since all microstates of a register value share a transition row, the retained register is exactly lumpable: its closure defect and route mismatch are zero. Its channel is a noisy copy of a permutation of the four register values, so, writing \(h=h_2(0.02)\approx 0.1414\) for the binary entropy of the output noise, \(H_{\mathrm{out}}=2\), \(H(\mathrm{out}\mid\mathrm{in})=h\), \(I(\mathrm{in};\mathrm{out})=2-h\approx 1.859\), and \(U_{\mathrm{loss}}=h\approx 0.141\). The only input information the output fails to account for is the bit flipped by noise.

\paragraph{The micro readout adds entropy but no information.}
Reading the output at full microscopic resolution changes the output entropies but not the information about the input. The destination microstate is drawn uniformly among the three copies of the register value, independently of everything else, so it adds \(\log_2 3\approx1.585\) bits to both \(H_{\mathrm{out}}\) and \(H(\mathrm{out}\mid\mathrm{in})\), which become \(3.585\) and \(1.726\). The mutual information and \(U_{\mathrm{loss}}\) are unchanged, and the entropy drop becomes negative, \(\Delta H=-\log_2 3\). This row illustrates why we use \(U_{\mathrm{loss}}\) rather than entropy drop: a richer output can have more entropy than the input without carrying any more information about it.

\paragraph{The erased output is a different object.}
Forgetting the control changes both closure and accounting. The route mismatch of the erased output is exactly \(24/25=1-2p_{\mathrm{gate}}=0.96\): microstates with the same target bit but different controls have nearly opposite futures, exactly as in the phase diagram of Section~\ref{sec:results-phase}. The closure defect of the point probe is also \(0.96\), and by Lemma~\ref{lem:worst-case-defect} no probe gives a larger value, so the probe does not hide a larger closure failure. On the information side, the output entropy drops to one bit, the conditional entropy stays at \(h\) because the noise on the reported bit is unchanged, and so \(I(\mathrm{in};\mathrm{out})=1-h\approx 0.859\) and \(U_{\mathrm{loss}}=1+h\approx 1.141\). The ratio of unretained input information between the erased and retained views is
\[
\frac{1+h}{h}=8.0701\ldots .
\]
That the ratio exceeds eight is equivalent to \(h_2(0.02)<1/7\), which we certify with rational upper and lower bounds on the logarithms involved (Appendix~\ref{sec:appendix-lean}). Figure~\ref{fig:information-budget} shows where the input information goes in each view.

Two further features of Table~\ref{tab:reversible-erased} are instructive. First, the conditional entropy is the same, \(h\), in the retained and erased views. The noise on the reported bit has not changed; what has changed is how much of the input the reported channel can still carry once the control is forgotten. Second, all three entropy-production rates are exactly zero. With no memory noise the control never changes, so the chain is reducible; on the uniform stationary law that we use for it, the kernel is symmetric and therefore in detailed balance. The decisive audit signal is thus not a coarse thermodynamic signature but the joint change in closure and retained information. Reading the laboratory through the erased lens does not physically erase a register, and it does not by itself establish a Landauer heat cost.

This is the central packaging-and-accounting lesson. Packaging is not an innocent matter of notation. The retained register keeps the full reversible carrier and supports a closed two-bit operator. The erased output reports a one-bit summary and turns a reversible gate into a many-to-one channel with large closure failure. What looks like ``the same XOR gate viewed more coarsely'' is, as an audited layer, a different object with different closure properties and an eightfold larger loss ledger. Discussions of physical logic often treat an irreversible description as a reversible one with some bookkeeping omitted. The comparison shows that omitting the bookkeeping changes the closure status of the layer itself.
